The browser app has three features that share one saved plan. The agent core runs the tool loop, the fixed crop rules, Statistics Canada economics and the fact-checker. The AI model is Gemma 4 31B through the Adaption API, behind a server proxy so the key never reaches the browser. Every fact comes from free public data: Environment Canada, Open-Meteo, Agriculture Canada, NASA, the Nova Scotia property registry and Statistics Canada.
